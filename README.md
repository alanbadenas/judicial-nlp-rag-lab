# Judicial NLP / RAG Lab

Academic project developed during Master's coursework to explore NLP techniques over legal/technical text, with emphasis on anonymization, embeddings, clustering/topic modeling, and retrieval-augmented search.

> **Academic project.** This repository is not presented as commercial experience.
>
> **Privacy note.** Real judicial records, identifiers, API keys, extracted text, embeddings, and derived datasets are intentionally excluded from this public repository.

The initial public snapshot preserves the core experimental source code while removing private/sensitive data and generated artifacts. A subsequent commit improves reproducibility, privacy safeguards, tests, and portfolio documentation.
